# Сайт химчистки «Чистота»

Исходный код сайта-визитки химчистки мягкой мебели и ковров в Шумерле.

## Разработка

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
```

Результат сборки находится в `dist/`. GitHub Actions автоматически собирает сайт и публикует его в GitHub Pages при каждом push в `main`.

Сайт: https://chistik21.github.io/himchistka21/
