# Чистик21 — выездная химчистка в Шумерле

Исходный код сайта-визитки: химчистка мягкой мебели и ковров с выездом к клиенту.
Аккаунтов и регистрации нет — посетитель сразу переходит к заказу.

## Контакты и ссылки

Все контактные данные собраны в `src/config.ts`:

- `contacts.phone` — телефон и ссылка `tel:`
- `contacts.schedule`, `contacts.visitNote` — график и описание выезда
- `contacts.max.href` — ссылка на профиль в мессенджере MAX (пока `null`)
- `contacts.vk.href` — ссылка на сообщество ВКонтакте (пока `null`)

Пока URL мессенджеров равны `null`, вместо нерабочей ссылки показывается
неактивная кнопка «скоро». После заполнения кнопки станут обычными ссылками.

## Тема

Сайт автоматически использует светлую или тёмную тему устройства
(`prefers-color-scheme`), без переключателя. Смена темы ОС применяется
к открытой странице сразу.

## Разработка

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
```

Результат — в `dist/`. GitHub Actions собирает сайт и публикует его в GitHub Pages
при каждом push в `main`.
